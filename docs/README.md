# Documentation

Project documentation is organized by purpose.

- `architecture/` — implementation architecture and component boundaries.
- `formal/` — mathematical definitions and formal results.
- `research/` — research questions, prior art, and limitations.
- `experiments/` — experimental methods and results.
- `adr/` — architecture decision records.
- `development/` — development and release documentation.

Documents are added as the corresponding parts of the project are established.
