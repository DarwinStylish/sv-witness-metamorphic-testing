# Research Documentation

This directory contains the research documents for SV-Witness Metamorphic
Testing. SV-Witnesses are software-verification (SV) witnesses exchanged
between verification tools and witness validators.

- [`problem-definition.md`](problem-definition.md) defines the research problem,
  initial scope, non-goals, and success and failure criteria.
- [`prior-art.md`](prior-art.md) records relevant prior work and the current
  boundary of the research question.
- [`hypotheses.md`](hypotheses.md) states the hypotheses to be evaluated and the
  evidence that would count against them.

Formal definitions will be maintained under `docs/formal/` as they are
established. Experimental methods and results will be maintained under
`docs/experiments/`.

Research claims in this directory may change as the semantic model, prior-art
review, and empirical evidence develop.
