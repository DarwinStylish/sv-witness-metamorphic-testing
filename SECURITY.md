# Security Policy

## Project status

This project is experimental and does not currently provide a stable production
release.

## Reporting an issue

Please report security issues privately rather than opening a public issue with
sensitive details.

Use GitHub private vulnerability reporting when it is available for the
repository. Otherwise, contact the maintainer using the email address listed in
`pyproject.toml`.

Correctness defects that could produce misleading validation results are also
important. Use private reporting when disclosure would create a security risk;
otherwise, report ordinary correctness bugs through the normal issue tracker.

Please include enough information to reproduce the problem when possible.
